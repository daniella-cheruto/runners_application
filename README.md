# Nairobi Safe Run 🏃‍♀️

A mobile application that helps runners in Nairobi stay safe by crowdsourcing safety data across running routes. Built to address the lack of localized, real-time safety information for urban runners in Nairobi — particularly tourists, beginners, and solo joggers.

## The Problem
Nairobi's inadequate infrastructure, dim street lighting, and personal security threats make it difficult for runners to find trustworthy safe routes. Existing apps like Strava and Nike Run Club don't provide localized, community-validated safety data tailored to Nairobi's urban environment.

## What It Does
- 📍 Track running routes via live GPS
- ⭐ Rate and review routes based on safety
- 📸 Submit safety feedback and incident photos
- 🚨 Report safety incidents with location pinning
- 🗺️ View community-validated safety ratings on an interactive map
- 👤 User authentication and profile management
- 🛡️ Admin dashboard for user and content management

## Tech Stack
- Flutter (Dart) — mobile frontend
- Supabase (PostgreSQL) — database, authentication & file storage
- Google Maps API — route visualisation & live GPS tracking

## System Modules
- **User Management** — registration, login, profile updates
- **Route Mapping** — explore, filter and view community routes
- **GPS Tracking** — live tracking with run history and summaries
- **Feedback & Incidents** — submit feedback, report incidents with photos
